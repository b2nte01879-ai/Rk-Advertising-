# R.K দৈনিক হিসাব

R.K Advertising and Digital House-এর দৈনিক হিসাবের অ্যাপ। React + Firebase (Firestore) দিয়ে বানানো, Vercel-এ হোস্ট করার জন্য রেডি।

## এই ফোল্ডারে যা আছে

- `src/App.jsx` — পুরো অ্যাপের কোড
- `src/firebase.js` — Firebase কনফিগারেশন ও ডেটাবেজ সংযোগ (আপনার প্রজেক্টের চাবি এখানেই বসানো আছে)
- `firestore.rules` — Firestore-এর নিরাপত্তা নিয়ম (Firebase কনসোলে বসাতে হবে)

## GitHub-এ কোড তোলা

আপনার কম্পিউটারে যদি GitHub Desktop বা git না থাকে, সবচেয়ে সহজ উপায়:

1. GitHub-এ আপনার `rk-hisab` রিপোজিটরিতে যান
2. **"Add file" → "Upload files"** এ ক্লিক করুন
3. এই ফোল্ডারের সবগুলো ফাইল ও ফোল্ডার (`src` সহ) টেনে এনে ছেড়ে দিন (drag & drop)
4. নিচে **"Commit changes"** চাপুন

## Vercel-এ ডিপ্লয় করা

1. **vercel.com** এ গিয়ে **"Sign up"** করুন, **"Continue with GitHub"** বেছে নিন
2. লগইন হলে **"Add New..." → "Project"**
3. আপনার `rk-hisab` রিপোজিটরিটা লিস্টে দেখাবে, তার পাশে **"Import"** চাপুন
4. Framework Preset অটো **"Vite"** ধরে নেওয়ার কথা — কিছু বদলানোর দরকার নেই
5. **"Deploy"** চাপুন, ১-২ মিনিট অপেক্ষা করুন
6. শেষে একটা লিংক পাবেন (যেমন `rk-hisab.vercel.app`) — এটাই আপনার স্থায়ী ঠিকানা

## Firestore Security Rules বসানো (গুরুত্বপূর্ণ)

Test mode ৩০ দিন পর বন্ধ হয়ে যায়, তাই স্থায়ী নিয়ম বসিয়ে দিন:

1. **console.firebase.google.com** → আপনার প্রজেক্ট → **Firestore Database → Rules** ট্যাব
2. যা লেখা আছে সব মুছে এই ফাইলের (`firestore.rules`) ভেতরের কোডটা পেস্ট করুন
3. **"Publish"** চাপুন

> **নিরাপত্তা নোট:** এই নিয়মে যে কেউ (লিংক পেলে) ডেটা পড়তে/লিখতে পারবে — ঠিক আগের Claude আর্টিফ্যাক্টের "Anyone with the link" ব্যবস্থার মতোই। ভবিষ্যতে চাইলে লগইন/পাসওয়ার্ড-ভিত্তিক সুরক্ষা যোগ করা যাবে।

## দৈনন্দিন ব্যবহার

- ডিফল্টে অ্যাপ **ভিউ মোডে** খোলে। উপরে ডানদিকের বাটনে চেপে **এডিট মোডে** যান তারপর এন্ট্রি দিন।
- এডিট মোডের পছন্দ প্রতিটা ব্রাউজার/ফোনে আলাদাভাবে মনে থাকে।
- হোম পেজে **"ব্যাকআপ ডাউনলোড করুন (CSV)"** চেপে যেকোনো সময় একটা কপি রেখে দিতে পারবেন।

## ফোনে অ্যাপ আইকন হিসেবে যোগ করা

Vercel লিংকটা Chrome/Safari-এ খুলে **শেয়ার → "Add to Home Screen"** করলেই ফোনের হোম স্ক্রিনে আইকন চলে আসবে।
